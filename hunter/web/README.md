# Hunter Web — הגרסה לחברים

Worker אחד של Cloudflare שמגיש את ממשק החיפוש ומריץ את הציד. כל חבר מדביק
מפתח Anthropic משלו (BYOK) — המפתח נשמר רק בדפדפן שלו, עובר בכותרת הבקשה,
ולא נשמר ולא נרשם בשרת. העלות של כל חיפוש נופלת על המפתח של מי שחיפש.

## פריסה (פעם אחת, ~5 דקות)

```bash
npm install -g wrangler          # כלי הפריסה של Cloudflare
cd hunter/web
python3 build.py                 # מטמיע playbooks + UI לתוך dist/worker.js
wrangler login                   # נפתח דפדפן — התחברות/הרשמה חינם
wrangler deploy                  # מקבלים כתובת https://hunter.<שם>.workers.dev
```

מומלץ — קוד גישה משותף כדי שרק 4 החברים ישתמשו:

```bash
wrangler secret put ACCESS_CODE    # מקלידים קוד, למשל: field2026
```

שולחים לחברים את הכתובת + הקוד. בכניסה הראשונה כל אחד פותח ⚙ הגדרות,
מדביק את המפתח שלו ואת הקוד — וזהו.

## עדכון

שינית playbook או UI? `python3 build.py && wrangler deploy` — אותה כתובת.

## מגבלות ידועות

- חנויות עם אנטי-בוט קשוח (ASOS, Farfetch) מקבלות קישור "ידני" — פותחים את
  החיפוש שלהן בקליק במקום תוצאה מובנית.
- מטבע: מחיר מוצג כפי שהחנות מחזירה אותו; המרה אמיתית — בהמשך.
- הפיד היומי והלמידה רצים אצל אנדריי; ה-Worker הוא החיפוש הממוקד בלבד.
