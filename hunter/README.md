# Hunter — צייד הדילים

מטרה: לאתר פריטים של מותגים מוכרים במחיר חריג, במקום לדפדף בקטלוגים.
הארכיטקטורה: רישום מקורות מורשים ← איסוף ← היסטוריית מחירים ← פנקס מותגים ← ציון דיל ← פיד יומי.

## קבצים

| קובץ | תפקיד |
|---|---|
| `registry.json` | רישום החנויות המאושרות (112, נבחרו בסוויפ). מקוריות מובטחת ע"י כך שסורקים רק חנויות מורשות — אין marketplaces. |
| `check_platforms.py` | מריצים **מקומית** פעם אחת (ואחרי כל הוספת חנויות): מסמן לכל חנות אם היא חיה, Shopify פתוח, או JSON-LD. |
| `shopify_adapter.py` | שכבה 1: מושך את כל הקטלוג מכל חנות Shopify מאומתת ומנרמל לפורמט אחיד. |
| `data/items.json` | הצילום האחרון של כל הפריטים (נדרס בכל ריצה — זה בסדר). |
| `data/history.jsonl` | **לא נדרס לעולם** — שורת מחיר לכל פריט בכל ריצה. זה מקור עוגני המחיר; בלעדיו אין "דיל". |

## סדר הרצה (על המחשב שלך)

```bash
python3 hunter/check_platforms.py     # פעם אחת — מאמת ומסמן פלטפורמות
python3 hunter/shopify_adapter.py     # ואז בכל יום — מושך ומצבר היסטוריה
```

מומלץ לתזמן את המתאם פעם ביום (Task Scheduler / cron). כל ריצה מוסיפה נקודת מחיר לכל פריט — אחרי כמה שבועות יש עוגן אמיתי לכל פריט.

## הצעדים הבאים (טרם נבנו)

1. מתאם JSON-LD גנרי לחנויות שכבה 2.
2. פנקס מותגים: דירוג איכות לכל מותג (LLM מציע, אנדריי מתקן).
3. חוקי מיסוי יבוא אישי (פטור עד $75, מע"מ עד $500, מכס מעל) + עלות עד הדלת.
4. ציון דיל: (מחיר עד הדלת ÷ עוגן היסטורי) × דרגת מותג × זמינות מידה.
5. פיד יומי קצר — אולי כהתראת טלגרם.
